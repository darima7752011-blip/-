# ФармаНавигатор

Справочник-навигатор по **100 крупнейшим фармацевтическим компаниям**, имеющим
производство или присутствие в России. Сделан как инструмент быстрого входа в
отрасль для **рекрутеров фарм-компаний**: масштаб игроков, локации производств,
численность персонала, продуктовый портфель.

## Что внутри

- **Обзор (дашборд)** — инфографика-сводка: топ-регионы по присутствию,
  соотношение российских / зарубежных / совместных компаний, распределение по
  сегментам (рецептурные, OTC, дженерики, оригинальные, биотех, вакцины),
  топ по выручке.
- **Каталог** — карточки 100 компаний, мощные фильтры (страна происхождения,
  наличие завода в РФ, регион, сегмент, терапевтическая область, наличие R&D),
  сортировка, поиск по названию и экспорт отфильтрованного списка в CSV.
- **Карточка компании** — самый важный экран: шапка со статусом, масштаб
  (выручка, сотрудники в РФ и глобально, год выхода на рынок РФ), производство
  на мини-карте с адресами заводов / мощностями / статусом GMP, продуктовый
  портфель, HR-блок для рекрутеров (типичные функции, R&D в РФ, карьерный сайт),
  ключевые события.
- **Карта производств** — все заводы на карте России, фильтр по сегменту,
  переход в карточку по клику на метку.
- **Сравнение** — 2–4 компании в таблице с подсветкой лучших значений.
- **Аналитика** — рейтинги по выручке, числу заводов, сотрудникам, сегментам и
  терапевтическим областям.
- **Словарь терминов** («Фарма для новичка») — GMP, дженерик, оригинальный
  препарат, R&D, локализация, регистрационное удостоверение, ЖНВЛП, биоаналог
  и др.

## Стек и запуск

Статический сайт на **React + Tailwind + Recharts + Leaflet** (подключаются по
CDN). Сборка не требуется.

Открыть `index.html` в браузере (нужно интернет-соединение для загрузки CDN и
карт). Для корректной работы рекомендуется отдать папку через любой статический
сервер, например:

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080/
```

## Как редактировать данные

Все сведения о компаниях находятся в одном файле **`companies-data.js`**.
Чтобы добавить компанию — скопируйте любой блок `{ ... }`, вставьте в конец
списка и замените значения. Код сайта (`index.html`) менять не нужно: фильтры,
карта, аналитика, сравнение и экспорт обновятся автоматически. Описание всех
полей — в комментарии в начале `companies-data.js`.

## О данных

Финансовые показатели приведены по Forbes «20 лучших фармпроизводителей России»
и данным AlphaRM / RNC Pharma по итогам 2025 года; сведения о заводах, регионах
и портфеле — из публичных корпоративных и отраслевых источников. Где данные
публично не раскрыты, стоит пометка «н/д» вместо оценочных цифр. Координаты
заводов приблизительны (уровень города). Данные носят справочный характер и
требуют проверки перед профессиональным использованием.
